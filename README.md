# 📸 Studio Lumen — Fotografia

> Site institucional da **Studio Lumen Fotografia**, desenvolvido com HTML, CSS e JavaScript puro.

🔗 **[Acesse o site ao vivo](https://subtle-rugelach-9f957a.netlify.app/)**

---

## 🖼️ Sobre o Projeto

O **Studio Lumen** é um estúdio de fotografia profissional. Este projeto é o site institucional da empresa, criado para apresentar os serviços, portfólio, planos e facilitar o contato com clientes.

---

## 📁 Estrutura de Arquivos

```
📦 studio-lumen/
├── 📂 css/              # Estilos da aplicação
├── 📂 images/           # Imagens utilizadas no site
├── 📄 index.html        # Página inicial
├── 📄 sobre.html        # Página Sobre nós
├── 📄 servicos.html     # Página de Serviços
├── 📄 portfolio.html    # Página de Portfólio
├── 📄 planos.html       # Página de Planos e Preços
├── 📄 depoimentos.html  # Página de Depoimentos
└── 📄 contato.html      # Página de Contato
```

---

## 🚀 Páginas

| Página | Descrição |
|---|---|
| `index.html` | Página inicial com apresentação do estúdio |
| `sobre.html` | História e informações sobre o estúdio |
| `servicos.html` | Serviços fotográficos oferecidos |
| `portfolio.html` | Galeria com trabalhos realizados |
| `planos.html` | Planos e pacotes disponíveis |
| `depoimentos.html` | Avaliações e depoimentos de clientes |
| `contato.html` | Formulário e informações de contato |
